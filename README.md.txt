# Inventory Optimization and Demand Forecasting

## Project Overview

This project focuses on inventory management using sales data.

The system analyzes historical demand and calculates important inventory planning metrics.

## Objectives

- Analyze historical sales data
- Estimate average daily demand
- Analyze recent demand
- Calculate safety stock
- Calculate reorder point
- Calculate Economic Order Quantity (EOQ)

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib

## Project Structure

- `data/` - Dataset
- `src/` - Python source codes
- `outputs/` - Generated visualizations
- `notebooks/` - Analysis notebooks

## Methods

The project uses statistical demand analysis and classical inventory management techniques such as:

- Safety Stock
- Reorder Point
- Economic Order Quantity (EOQ)
